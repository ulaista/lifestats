# Android

Бот, Mini App, ассистент (текст и голосовые в чате), задачи, расходы, разборы и напоминания работают на Android
как есть — они живут на сервере и в Telegram. Ниже — как подключить данные телефона.

| Что | Как на Android | Адрес на сервере |
|---|---|---|
| Сон, шаги, пульс, ВСР, калории, тренировки, вес | **Health Connect** + приложение **HC Webhook** | `/hc` |
| Календарь | ссылка iCal из Google Календаря (сервер забирает сам) | команда `/ical` |
| Экранное время | **MacroDroid** или **Tasker**: «приложение запущено / закрыто» | `/screen` |
| Голосовой ассистент | голосовое сообщение боту или **HTTP Shortcuts** | `/ask` |
| Напоминания | задачи в самом боте (Google Tasks не поддерживается) | — |

`$SERVER` ниже — адрес вашего сервера (`https://<ваш-проект>.vercel.app` или ваш домен).
Ключ данных (`INGEST_TOKEN`) бот показывает командой `/shortcut`, ключ ассистента (`ASK_TOKEN`) — `/siri`.

## 1. Здоровье: Health Connect → HC Webhook

**Health Connect** — системное хранилище здоровья Android (встроено в Android 14+, на 9–13 ставится из Google Play).
В него пишут Samsung Health, Google Fit, Fitbit, Garmin Connect, Mi Fitness/Zepp (через их настройки синхронизации)
и многие часы.

1. Убедитесь, что ваше фитнес-приложение пишет в Health Connect (например, Samsung Health → Настройки →
   Health Connect → разрешить запись).
2. Установите **HC Webhook** — [Google Play](https://play.google.com/store/apps/details?id=com.hcwebhook.app) или APK из
   [GitHub Releases](https://github.com/mcnaveen/health-connect-webhook) (через Obtainium).
3. Дайте приложению доступ на чтение: шаги, сон, пульс, пульс покоя, вариабельность пульса, активные калории,
   дистанция, тренировки, вес.
4. Добавьте вебхук:
   - URL: `$SERVER/hc`
   - Header: `Authorization` = `Bearer <INGEST_TOKEN>`
5. Синхронизация: каждые 30–60 минут или по расписанию (например, 09:00, 14:00, 22:00). Нажмите «Sync Now» для проверки.
6. В боте — `/status`: у «Здоровье» должно появиться «последние данные N мин назад».

Как сервер считает:
- приложение присылает только новые записи — сервер хранит их и пересчитывает часы, повторная отправка не удваивает;
- шаги с телефона и часов в одном часе не складываются: берётся больший источник (как в «Здоровье» iPhone);
- фазы сна (light → основной, deep, REM, awake) считаются как на iPhone; «сон без фазы» внутри сессии с фазами — основной сон;
- удаления на телефоне доходят до сервера.

## 2. Календарь по ссылке

Работает с Google, iCloud (публичный календарь), Outlook и любым `.ics`.

1. **Google Календарь** на компьютере: ⚙️ Настройки → слева выберите календарь → «Интеграция календаря» →
   **«Секретный адрес в формате iCal»** → скопировать.
2. Отправьте боту: `/ical add <ссылка>` — бот сразу загрузит события на месяц вперёд и будет обновлять их раз в час.
   После этого сообщение со ссылкой лучше удалить из чата: ссылка даёт доступ к календарю.
3. `/ical` — список подключённых календарей, `/ical del <номер>` — убрать.

События из календаря бот показывает и учитывает в «Распредели задачи», но не меняет их (меняются в самом календаре).

**Записи бота → Google Календарь:** ссылку на подписку даёт `/calendar`. Google Календарь в браузере →
«Другие календари» → **«+» → «Добавить по URL»**. Google обновляет такие календари раз в несколько часов.

Ссылки можно задать и на сервере переменной `CALENDAR_ICS_URLS` (через запятую).

## 3. Экранное время: MacroDroid или Tasker

Сервер считает время по событиям «открыто / закрыто», как и на iPhone.

**MacroDroid** (бесплатно до 5 макросов):
1. Новый макрос → Триггер **«Приложение запущено/закрыто»** → выберите **одно** приложение → «Запущено».
   Добавьте второй триггер того же приложения → «Закрыто».
2. Действие **«HTTP-запрос»**: метод **POST**, URL `$SERVER/screen`,
   заголовок `Authorization: Bearer <INGEST_TOKEN>`, тип содержимого `application/json`,
   тело: `{"app":"Instagram"}`.
3. Повторите для каждого приложения (Telegram, YouTube, TikTok, браузер…).

**Tasker:** профиль «Приложение» → выбрать приложение; задача на вход и задача на выход — обе действие
**HTTP Request** (POST, тот же URL, заголовок и тело).

Одно правило — одно приложение: сервер сам определяет открытие и закрытие, открытие другого приложения закрывает
текущую сессию. Можно явно указать событие: `{"app":"Instagram","event":"open"}` / `"close"`.

## 4. Голосовой ассистент

Проще всего — **голосовое сообщение боту**: оно распознаётся и выполняется так же, как текст.

Кнопка на рабочем столе — **HTTP Shortcuts** (бесплатно, открытый код, Google Play / F-Droid):
1. Новый ярлык → метод **POST**, URL `$SERVER/ask`.
2. Заголовок `Authorization` = `Bearer <ASK_TOKEN>` (ключ из `/siri`).
3. Переменная `text` типа «Текстовый ввод»; тело запроса — JSON `{"text":"{{text}}"}` (вставьте переменную через меню).
4. Обработка ответа → показать в диалоге (в ответе поле `speech`).
5. Добавьте ярлык на рабочий стол; для голосового ввода нажмите микрофон на клавиатуре.

Ответ и карточки также приходят в чат с ботом.
