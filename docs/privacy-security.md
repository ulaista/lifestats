# Безопасность, приватность, резервные копии

## Модель доступа

| Что | Как защищено |
|---|---|
| Бот | отвечает только владельцу (привязка одноразовым кодом `npm run pair`) и только в личном чате |
| Mini App и его API | подпись Telegram `initData` (HMAC от токена бота), срок 24 ч, проверка владельца |
| Вебхук `/tg` | секрет `X-Telegram-Bot-Api-Secret-Token`, выводится из токена бота |
| Приём данных `/ingest`, `/health`, `/calendar`, `/reminders`, `/screen` | ключ `INGEST_TOKEN` |
| Siri `/ask` (может управлять ассистентом) | отдельный ключ `ASK_TOKEN` |
| Планировщик `/tick`, `/cron` | `CRON_SECRET` |
| Подписка на календарь `/cal/<ключ>.ics` | 128-битный ключ в адресе (выводится из токена бота) |

Ключи сравниваются за постоянное время. Ошибки сервера наружу не раскрываются. В Mini App все данные выводятся
как текст (не HTML).

**Токен бота — главный секрет**: от него зависят подпись Mini App, секрет вебхука и адрес календаря. При утечке —
`/revoke` в @BotFather, новый токен в настройки, `scripts/cloud-setup.ts` заново.

## Защита ассистента от чужих инструкций

Текст пересланных сообщений, постов каналов и результатов поиска — данные, а не команды. Ассистенту это прямо
указано, а для пересланных сообщений доступны только инструменты создания записей (ничего не изменить и не удалить).

## Куда уходят данные

| Сервис | Что получает | Нужен ли |
|---|---|---|
| Хостинг (Vercel / ваш сервер) | всё — там работает код | да |
| База (Turso / SQLite у вас) | всё, что хранится | да |
| Telegram | сообщения бота вам, файлы бэкапов (зашифрованы) | да |
| ИИ-провайдер (Groq/OpenAI/…) | сообщения ассистенту, контекст (план, траты), итоги для разборов, голосовые | нет — без ключа ассистент выключен |
| Last.fm | ничего не получает, только отдаёт вашу историю прослушиваний | нет |
| cron-job.org | только вызывает `/tick` с секретом | нет (на своём сервере не нужен) |

Сырые данные «Здоровья» в ИИ не отправляются — только средние значения для разборов.
Если нужно полностью локально: свой сервер + SQLite + локальная модель (Ollama).

## Ключи на iPhone

`INGEST_TOKEN` и `ASK_TOKEN` хранятся внутри «Команд». **Не делитесь командами по iCloud-ссылке.**
При подозрении на утечку — новый ключ в настройки сервера и в команды (`/calendar`, `/siri` покажут новые строки).

## Резервные копии

- С `BACKUP_KEY` бот каждое воскресенье (после 04:00) присылает файл `lifestats-backup-ДАТА.lsb`, `/backup` — сразу.
- Формат: JSON всех таблиц → gzip → AES-256-GCM. Telegram хранит файл, но прочитать не может;
  изменённый файл не расшифруется.
- **Сохраните `BACKUP_KEY` в менеджер паролей** — без него копии не открыть. Не храните ключ в том же чате.
- Восстановление:
  ```bash
  npm run backup:restore -- lifestats-backup-2026-01-04.lsb          # что внутри и сколько записей сейчас
  npm run backup:restore -- lifestats-backup-2026-01-04.lsb --apply  # заменить содержимое базы
  ```
  Цель — база из `.env` (Turso) или локальная SQLite, если `TURSO_DATABASE_URL` пуст.

## Перед тем как делиться форком

В репозиторий не должны попадать `.env`, `data/`, `.vercel/`, `api/index.mjs`, `*.lsb` — они уже в `.gitignore`.
